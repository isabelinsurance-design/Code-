Work Tracker Settings

Set this up once on each employee's computer.

What is recorded: the site name (for example humana.com), when and for how long it was in front of you, and whether the computer was active, idle or locked. Never full web addresses, page titles, page contents, passwords, member data or what you type. When you use Nextiva in Chrome, it also notices when a call starts and ends (times only: no numbers, names or audio). You may get a reminder if you're idle or on a non-work site for a while.
